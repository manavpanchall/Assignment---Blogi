# Blogi - Full Stack Blogging Platform

A modern blogging platform with user authentication and CRUD operations for blog posts, built with React (frontend) and FastAPI (backend).

## Features

- User registration and login with JWT authentication
- Create, read, update, and delete blog posts
- View all posts sorted by creation date
- Responsive design with Tailwind CSS
- Secure API endpoints with token verification

## Technologies Used

**Frontend:**
- React 18
- React Router 6
- Tailwind CSS
- Axios for API calls
- JWT authentication

**Backend:**
- FastAPI
- PostgreSQL
- SQLAlchemy ORM
- JWT authentication
- Alembic for database migrations
